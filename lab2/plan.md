# Игра жизнь

## Требования

- Считывать вселенную из файла.
- Если файл не подан, использовать поле по дефолту (желательно интересное)
- Режим "оффлайн" - сделать N шагов и вывести результат
    - `-i x` или `--itrations=x` - количество итераций
    - `-o filename` или `--output=filename` - выходной файл
- После старта программа ожидает команды:
    - `dump [filename]` - сохранить вселенную в файл
    - `tick [n=1]` или `t [n=1]` рассчитать n итераций и напечатать результат. На экране должно отобразиться:
        - Имя вселенной
        - Правило перехода
        - Номер текущей итерации
        - Самое поле непосредственно
    - `exit` - завершить игру
    - `help` - справка о командах
- Расчёт по разным правилам перехода
- Поле тороидально
- **Не допускается** единственный *God object*. Программа должна быть разбита на классы
- Юзаем стандартные либы
- Основной функционал должен быть покрыт юнит-тестами
- Сделать демо.

### TerminalEmulator
Этот класс общается с пользователем.
Действует по следующему алгоритму.
1. Ввод команды
2. Если команды нет, выводит сообщение об ошибке. `goto 1`
3. Если команда есть, то уже там делает чё-то.
